# marketing/

Everything for promoting the game: brand, campaigns and video production (ADR-0011).

| Folder | What goes here |
|---|---|
| `brand/` | Logo, wordmark, key art, brand guide. Colours come from `packages/tokens` |
| `briefs/` | One folder per campaign: `brief.md` with goal, audience, channels and success measure |
| `scripts/` | Voice-over and on-screen text drafts, one file per video |
| `storyboards/` | Shot lists, beat sheets, board images |
| `replays/` | Replay files plus "director tracks" (camera, slow-motion) used as trailer footage |
| `captures/` | `manifest.json` only. Raw captures live in R2 (ignored here) |
| `compositions/` | HyperFrames video projects, one folder per video |
| `social/` | Per-platform cut specs (9:16, 1:1, 16:9), captions, thumbnails |
| `renders/` | Ignored. Final renders are uploaded to storage and recorded in a manifest |

Rule: no franchise, studio or game names in any marketing material.
