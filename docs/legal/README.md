# docs/legal/

Only **templates and policies** go here: consent form text (versioned, e.g. `consent/v1.md`) and privacy notes.
Signed consent forms, photos and any personal data are **never** committed. They are stored privately (ADR-0012).
Applicable law for the launch market: Bangladesh Personal Data Protection Act 2026 (see `docs/research/art-style-research.md`).
