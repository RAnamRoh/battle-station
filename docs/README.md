# docs/

| Folder | Purpose |
|---|---|
| `process/` | How we work (start with `how-we-work.md`) |
| `decisions/` | ADRs: one file per decision. Superseded, never deleted |
| `game-design/` | Living game-design prose: feel, mechanics, fighter sheets. Rules belong in `openspec/specs/`; numbers belong in `content/` |
| `architecture/` | Diagrams and explanations of how the system fits together |
| `content-guide/` | How to author fighters, stages, tenants and art styles |
| `runbooks/` | Deploying, incidents, data deletion |
| `legal/` | Consent **text templates** and privacy notes. Never actual personal data |
| `research/` | Research notes behind the decisions (dated snapshots, not kept current) |

Behaviour lives in `openspec/specs/`. The reasons behind decisions live in `docs/decisions/`.
